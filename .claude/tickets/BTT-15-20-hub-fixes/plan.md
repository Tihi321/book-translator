## Tickets

- [x] **BTT-15: no false "untranslated" on kept VN lines.** `deterministicChecks` in `pipeline/qa.ts` flags target == source with >= 3 words; inline speaker tags (`<1>INÈS (angry):</1>`) count as words. Fix: count only words outside inline tags; and a segment the brief marks as kept (or a glossary row marked keep, if such a flag exists) is not flagged. Test: `<1>INÈS (angry):</1> Basszus.` unchanged → no major; a 4-word real sentence left untranslated → still flagged.
- [x] **BTT-16: the glossary pass must not overwrite the user's brief.** `runner.ts` (~174-175) replaces a brief set with `set_brief` by the brief the first glossary pass returns. Fix: merge: keep every field the user set, fill only empty fields from the pass. Test: user brief with editorial rules + a pass returning another brief → user rules kept, empty fields filled.
- [x] **BTT-17: whole-word glossary matching.** Matching is case-insensitive substring with a 60-entry cap per chunk ("Da" in "day", "trap" in "trapped"). Fix: Unicode-aware whole-word matching for the source term (multi-word terms as a phrase). QA's glossary check: accept an inflected target form (match on a stem, e.g. the target term minus its last 1-2 letters for terms longer than ~4 letters, or another simple rule; document it). Tests for both.
- [x] **BTT-18: translated EPUB cover and alt text.** An EPUB export keeps the source cover PNG (English title baked in) and the English alt text ("Cover of ..."). Fix: (1) the cover alt text uses the translated title and a target-language word for "cover" where known (fallback: just the translated title); (2) an export option for a plain title-page cover made from the translated title and author (an SVG cover page is fine in EPUB 3; no new native deps), exposed where the other export options are (MCP tool arg and, if simple, the UI). Default stays the source cover. Tests: alt text and the generated cover in the package.
- [x] **BTT-19: stale `engine.lock` with a reused pid.** A lock whose pid now belongs to an unrelated process (svchost.exe) blocked the start. Fix: write the process start time (and/or name) into the lock and treat the lock as stale when the live pid's start time or name does not match; older locks without the field: check the process name looks like Book Translator/node/electron. Test with an injected process lookup.
- [x] **BTT-20: client task loop ergonomics.** (1) `wait_for_progress` returns when any role has a task waiting: add an optional `role` filter (and raise the `timeoutSec` cap if nothing in the MCP transport needs 60; keep 60 as the default). (2) A task leased by a client that stopped holds the pipeline until the 30-min lease expires: release a session's leases when its MCP session closes, and/or a shorter lease renewed on the client's calls; pick what the code supports cleanly and document it. (3) Minor QA findings never reach a fixer: an opt-in project setting to send minors to the fixer too (default off), and minors listed in the progress/status output. Tests per part.

## Done notes (2026-10-23)

Causes were confirmed in the code before each fix; all matched the roadmap text.

- **BTT-15** (4cdd689): `pipeline/qa.ts` `looksUntranslated`, new `textOutsideTags` in `formats/inline.ts`. Counts words outside paired tags (a line made only of tagged text counts in full); glossary keep rows (source == target) are removed from the text before counting. Choice: the brief's "kept as is" rule is free text, so it is not parsed; the keep row is the way to silence a line. Tests in `tests/agents.test.ts`.
- **BTT-16** (98f57f8): the brief is a free markdown string, so the merge is textual: `mergeBriefText` in `pipeline/glossary.ts` keeps the user's text verbatim and appends a field line (Genre, Tone, Register, Narrator, Address) only when the text has no mention of that label, and characters whose name it does not contain. Runner uses it. Tests in `tests/glossary.test.ts` and `tests/pipeline.test.ts` (set_brief, then start).
- **BTT-17** (cd99ad4): `relevantEntries` matches with a cached `(?<![\p{L}\p{N}])term(?![\p{L}\p{N}])` regex (spaces in a term match any white space run). Stem rule (`hasTarget`): every word of the target must have its stem in the translation; stem = word minus last 2 letters (7+ letters), minus last 1 (5-6), whole (shorter). Tests in `tests/glossary.test.ts`, `tests/agents.test.ts`.
- **BTT-18** (5450b90): new `publish/cover.ts` (`coverAltText`, `titleCoverSvg`), `formats/epub.ts` write path, `WriteOptions.cover`, export command/MCP `cover`, CLI `--cover title`. Alt text "<word>: <translated title>" for a known language code (hr, sr, de, fr, ...), else the translated title alone; applied to images that are the manifest cover image or whose alt starts with "cover". `cover: title` writes `translated-cover.svg`, moves the `cover-image` property and `meta name=cover` to it, points the cover page's img at it, or adds a cover page first in the spine when the book has none; the old PNG stays in the package, unreferenced as cover. Deviation: no UI control (the plan said "if simple"; the UI has no export options dialog). Tests in `tests/epub.test.ts`.
- **BTT-19** (4cbd198): `store/lock.ts`: the lock is `pid\nstartMs\nname` (first line still the pid, so older readers work). `lockHolderAlive` with an injected `ProcessLookup`; default lookup is PowerShell `Get-Process` on Windows and `ps` elsewhere, and "cannot tell" respects the lock. Start times match within 10 s; without a start time the live name must look like Book Translator, Node or Electron. Tests in `tests/lock.test.ts`.
- **BTT-20** (8d8e1c6): (1) `role` filter on `wait_for_progress`; the 60 s cap stays (the MCP SDK client's default request timeout is 60 s, so a longer wait would time out on the client side). (2) The MCP endpoint is stateless (`mcp/http.ts`: a new transport per POST, no session id), so a closed session cannot be seen. Chosen instead: default lease 10 min (was 30), `leaseMinutes` argument (1-60) on `get_client_task`, a refused `submit_client_task` renews the lease, and `release_client_task` with `project` and/or `role` frees every leased task of a dead client. (3) `fixMinorIssues` setting (default off; `update_project_settings`, create_project, a checkbox in the settings tab); minors listed as `minorIssues` and `minors` (first 30) in `wait_for_progress` and in `engine status`. Tests in `tests/client.test.ts`, `tests/pipeline.test.ts`.
