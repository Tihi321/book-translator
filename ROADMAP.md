## Open: found by the hub's *Ash & Brass* run (2026-11-15)

- **BTT-31 (done, merged 2026-11-16 from `BTT-31_retry-and-export`; creative-hub REQ-0025, bugs 5 and 6; plan `.claude/tickets/BTT-31-retry-and-export/plan.md`): a segment mismatch never reached the next model, and an export with a failed chunk was silent.** Book 2 hr: chunk 37 failed four times on `acp/claude/claude-sonnet-5` (twice, split, twice) while `acp/antigravity/gemini-4-argon`, second in the translator list, was never asked; it translated the chunk on the first manual `retry_chunk`. The router falls back only on provider errors, and a mismatch is a reply that arrived. Then `export_project` wrote the book with 19 English paragraphs and no warning. Fix: (1) two mismatches on a model move the chunk to the next model of the role's list (`CallRequest.skipModels`), the split comes only after every model failed, each switch is logged, and a one-model list is unchanged; (2) export refuses while any block is untranslated (a failed or pending chunk), naming the chunks, the block count and `retry_chunk`; `allowPartial: true` (MCP, protocol, CLI `--allow-partial`, the app's "Export anyway") exports anyway with a warning; `engine translate` passes it. The CLI and the UI ("Export anyway", warning toasts) are built but UNTESTED; not done: the live check on a real book (tests only, the app was in use).

- **BTT-32 (branch `BTT-32_segment-reask-and-source-refresh`; creative-hub REQ-0026; plan `.claude/tickets/BTT-32-segment-reask-and-source-refresh/plan.md`): ask again only for the missing segments, refresh a project's source, and the typography field.** (1) `acp/claude/claude-sonnet-5` dropped or repeated one segment id in long chunks; the whole reply was thrown away. Now a reply with a few missing ids or garbled repeats (and no ids that were not asked for) keeps the rest, and the same model is asked for just those, with the passages around them (twice at most), before BTT-31's full retry, next model and split. (2) A hand edit to the English book 3 never reached its Croatian project: the project id holds the source hash, and nothing re-read the source. `refresh_source {projectId, sourcePath?}` (CLI `engine refresh`, the app's Refresh source) re-reads it into the same project: unchanged blocks keep their translation, QA verdict and hand edits, changed and new blocks go into new pending chunks, removed ones are dropped, the old files are backed up; export refuses while the source file changed. Not for visual-novel folders or packs. (3) BTT-30's leftover: dialogue style, quote marks and notes in the project settings tab.

## Done (found by the creative hub's HUB-02 and HUB-05 runs, 2026-10-22; plan in `.claude/tickets/BTT-15-20-hub-fixes/plan.md`)

Seen on the master build (2a21970) while Claude translated *The Clockless God* VN script and *The Hour That Happens Twice* into Croatian through the client provider. Each item was its own commit on `BTT-15-20_fixes`.

- **BTT-15: QA flagged kept lines in VN folders as "untranslated".** Only the words outside inline tags count now, and glossary keep rows (source equals target) do not count. A line the brief says to keep, with 3 or more words and no keep row, is still flagged (the brief is free text and is not parsed).
- **BTT-16: the glossary pass overwrote the brief.** The pass now merges: the user's brief text stays, only the fields and characters it lacks are added.
- **BTT-17: glossary matching was a substring match.** Whole word or phrase, Unicode-aware. QA accepts an inflected target by stem (word minus its last 1 to 2 letters).
- **BTT-18: an EPUB export kept the English cover.** The cover's alt text is translated; `cover: title` (MCP, CLI `--cover title`) replaces the image by a generated title page (an SVG image until BTT-29). Default unchanged. No UI control yet.
- **BTT-29: Kindle showed the Croatian EPUBs as fixed layout** (done when merged; branch `BTT-29_kindle-svg-cover`; creative-hub request REQ-0008; plan `.claude/tickets/BTT-29-kindle-svg-cover/plan.md`). The cause was the SVG `cover-image` that `cover: title` added together with an image-only first page. The writer now never emits an SVG cover or an image-only page: `cover: title` makes the page that shows the cover image a reflowable text title page (title and author), leaves a source text cover or title page as it is, and otherwise adds `translated-title.xhtml` first in the reading order. A raster title cover would need a new native dependency and is not planned. Default (`source`) unchanged.
- **BTT-19: a stale `engine.lock` blocked the start when its pid was reused.** The lock holds the pid, start time and name; a live pid with another start time, or (older locks) a name that is not Book Translator, Node or Electron, is taken over.
- **BTT-20: client task loop ergonomics.** `wait_for_progress` has a `role` filter (the 60 s cap stays: the MCP client's default request timeout is 60 s); the lease is 10 minutes (`leaseMinutes` up to 60), renewed by a refused answer, and `release_client_task` frees every leased task of a project or role (the endpoint has no sessions, so a dead client cannot be noticed); the `fixMinorIssues` setting (default off, a checkbox in the settings tab) sends minor QA issues to the fixer, and minors are listed in `wait_for_progress` and `engine status`.
